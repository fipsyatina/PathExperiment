# Перевірки першої версії

Локально перевірено на Windows x64 у Release-збірці з MSVC та SFML 3.1.0.

- 27 перевірок ядра: коректність маршруту й вартості, стіни, недосяжна ціль,
  нульова довжина, події кроків, ізоляція карти, детермінованість і формат файлу.
- 80 невеликих карт із фіксованим seed: Dijkstra та A* порівняно з незалежним
  алгоритмом Bellman–Ford; кожний знайдений маршрут перевірено окремо.
- Нативний smoke-тест: малювання та стирання через події вводу, безперервний
  пензель, розміщення S/G, повзунок швидкості, запуск/пауза через кнопки,
  один крок, зупинка анімації на паузі та збереження всіх кроків після затримки.
- Перевірено інвалідацію результатів після редагування, порівняння алгоритмів,
  запис і повторне читання файлу та всі п'ять готових прикладів.
- GIF і скриншот у README отримано з нативного SFML-вікна.

Очікувані вартості прикладів:

| Карта | Мінімальна вартість |
| --- | ---: |
| Відкрита | 70 |
| Лабіринт | 126 |
| Дешевий обхід | 49 |
| Заблокована ціль | маршруту немає |
| Вузький прохід | 35 |

Windows-пакет використовує статично зібрані бібліотеки та C++ runtime.
Перевірка PE-залежностей показала лише системні Windows DLL; SFML DLL та
Visual C++ Redistributable для цього пакета не потрібні.

GitHub Actions окремо збирає ядро на Linux у Debug/Release та застосунок на
Windows у Release. Актуальний результат CI доступний у вкладці Actions
репозиторію. Локальна нативна перевірка не є перевіркою графічного застосунку
на Linux/macOS або ручним проходженням системного діалогу вибору файлу.
